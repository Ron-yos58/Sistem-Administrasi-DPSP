# Sprint 1 Plan

## Tujuan

Mengganti proses batch Spreadsheet menjadi web app Apps Script yang aman dan dapat dioperasikan per permohonan.

## Pekerjaan

1. Audit panduan dan script legacy.
2. Normalisasi permohonan, dokumen, pegawai, dan perjadin.
3. Implementasi CRUD dan akses.
4. Implementasi Docs, PDF, dan draft Gmail.
5. Implementasi frontend responsif.
6. Dokumentasi deployment.
7. Static check.

## Kriteria Sukses

- Satu permohonan mendukung banyak dokumen.
- Routing email per dokumen.
- Perjadin memakai key stabil.
- Draft/file idempotent.
- UI desktop/mobile.
- Deployment terdokumentasi.
